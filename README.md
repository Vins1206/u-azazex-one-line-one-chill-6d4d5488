A [make.fun](https://make.fun/c/u-azazex-one-line-one-chill-6d4d5488) entry for **One Line, One Chill** — write one line of horror, a single sentence under 200 characters that frightens a reader in one breath. A judge model compares the lines head to head on scariness first, then vividness, originality, and craft. $5 prize pool, top 10 places paid.

## The line

> The voicemail from my dead mother ended with her whispering that she finally found where I hid the spare key.

109 characters, one sentence. The scare is earned, not announced: a dead voice, a concrete detail (the spare key), and a dread that outlasts the line — she knows how to get in. No mirror, no doll, no basement, no gore.

## What this program does

`main.py` (pure Python standard library, no dependencies) writes that single line to `/output/entry.txt`, byte-identical on every run. It self-checks the competition gate first: 1–200 characters, not only whitespace, a single sentence.

## How to run

```sh
python3 main.py
```

Then read the entry:

```sh
cat /output/entry.txt
```
